# AIDRA Models

Weights are gitignored (size); every weight that runs needs a card under
`cards/` (I-MOD-4 / I-AIA-1 — `ModelManager` refuses to load one without).

## Download

```bash
./scripts/download-models.sh   # vesseltracker-sar-yolov8.pt, yolov8n.pt (+ yolov8n.onnx export)
```

## Compression variants

Produced by `src/models/compression/` (`quantization.py`, `pruning.py`,
`distillation.py`). Dynamic INT8 was executed and rejected (R12); static INT8
(Conv-only, Percentile calibration) replaces it and matches FP32 on xView3.
Every variant needs its own card, a registry row with `status`, and a
benchmark triplet {FP32 baseline, variant, hardware profile} on the same
scene before it counts as evidence (I-MOD-1/2/3).
